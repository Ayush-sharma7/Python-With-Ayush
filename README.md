## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Ayush-sharma7/Python-With-Ayush.git
cd Python-With-Ayush
```

Run any Python program:

```bash
python filename.py
```

For example:

```bash
python fibonacci.py
```

> Some filenames contain spaces, so make sure to use the exact filename when running them.
